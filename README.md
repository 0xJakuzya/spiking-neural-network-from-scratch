# Spiking Neural Network from Scratch

An experimental implementation of a Spiking Neural Network (SNN) built from scratch using NumPy, focusing on Leaky Integrate-and-Fire (LIF) neurons and Spike-Timing-Dependent Plasticity (STDP).

The project explores how spiking neural networks process EEG signals and learn temporal patterns through unsupervised synaptic plasticity.

## Dataset

The project uses EEG recordings from the EEG Motor Movement/Imagery Dataset (PhysioNet).

- 109 subjects
- 64 EEG channels
- 160 Hz sampling frequency
- Two conditions: Eyes Open / Eyes Closed
